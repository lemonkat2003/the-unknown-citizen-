# The Unknown Citizen — v35 Mobile Edition (based strictly on v33)

Includes v33 game rules, story, original artwork and music, with responsive mobile layout changes only.

## Mobile improvements
- A streamlined sticky header and horizontally scrollable navigation.
- Large object and witness buttons below scenes on phones, avoiding overlapping tiny hotspot targets.
- Compact interview portraits, larger dice/question tap areas and scrollable evidence panels.
- Final Report stacks above Field Journal on phones. Selecting a report answer scrolls to the journal; tapping a fact fills the answer and scrolls back to it.
- Full-height, scrollable evidence and final-reveal panels with safe mobile spacing.
- Reduced animation option for users with motion preferences.

## Deploy
Upload `index.html` and `municipal_nocturne.mp3` to your GitHub Pages root. `standalone.html` is the one-file option containing the soundtrack.

Existing v33 saves should remain compatible because the storage key and game mechanics were not changed.
